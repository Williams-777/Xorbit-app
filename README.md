# X-Orbit

X-Orbit is a cross-platform local file transfer app built with Flutter.

## Features
- Fast local file sharing
- Windows ↔ Android transfer
- Clipboard sync
- Cross-platform support
- Transfer History
- Hotspot support
- No Internet
